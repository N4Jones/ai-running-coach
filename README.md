# AI Running Coach

Build your own AI running coach with Claude or ChatGPT and your Garmin: the Garmin MCP link, copy-ready prompts and a step-by-step setup guide for each. Use the switch at the top of the page, or link straight to the ChatGPT version with `#chatgpt`.

The whole site is `index.html`, served with GitHub Pages.
